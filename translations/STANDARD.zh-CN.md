## 1. 目的与范围

CRLN-TRG-001 为全球临床研究从业人员定义了一套通用的、公开发布的能力框架。其目的
是使临床研究能力在国家、语言和岗位之间**可测量、可比较、可迁移**，并锚定于已获
认可的全球标准（ICH E6(R3) 药物临床试验质量管理规范），同时与联合工作组（JTF）
临床试验能力框架保持一致。

框架定义了八个岗位序列：临床研究协调员、临床研究监查员、临床试验管理专员、临床
数据管理员、临床试验／项目经理、药政事务专员、药物警戒／药物安全专员，以及主要
研究者。本框架向全球学习者免费提供。

## 2. 标准能力分类法（10 个领域）

CRLN-TRG-001 将临床研究能力划分为十个标准领域（D-01…D-10），与 ICH E6(R3) 的
结构保持一致：

| 编号 | 领域 |
|---|---|
| D-01 | GCP 原则与伦理 |
| D-02 | 知情同意流程 |
| D-03 | 方案依从性与偏离 |
| D-04 | 不良事件与安全性报告 |
| D-05 | 试验用药品管理 |
| D-06 | 数据完整性与原始文件 |
| D-07 | 伦理委员会（IRB／IEC）递交 |
| D-08 | 试验主文件与药政文档 |
| D-09 | 中心管理与监查 |
| D-10 | 药物警戒与药政递交 |

在 1.1 版中，本框架包含 **48 条能力描述**（八个岗位序列 × 每个序列六个领域），
跨越 **2 个已发布版本**（1.0 与 1.1）。

**关于领域编码的重要提示。** D1–D6 是各岗位序列内部的位置编码：监查员的 `D1` 与
临床数据管理员的 `D1` 是不同的能力。任何比较都必须使用完整标识
`CRLN-<岗位>-<Dn>`。

## 3. 标准对照表

CRLN 的做法是将已获认可的标准付诸实施，而非另创一套。每个标准领域均对照至联合
工作组临床试验能力框架以及 ICH E6(R3)，并标注与 ACRP、SOCRA 的相关性。条款引用
统一采用 **ICH E6(R3) 附件 1** 的编号。

*对照映射为暂定内容，有待领域专家审校。*

**完整对照表不作翻译。** ICH E6(R3) 的条款编号与 JTF 标识符不依赖于语言，在非官方
译本中重新诠释法规引用只会增加风险而不会增加用处。请参阅 `../STANDARD.md` 第 3 节。
