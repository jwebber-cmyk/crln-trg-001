# Who uses CRLN-TRG-001

A voluntary, public register.

## Why this file exists, and why it is honest about being incomplete

CRLN-TRG-001 is CC BY 4.0. You may use, adapt and translate it with no
permission, no contract and no conversation, and `ADOPT.md` says so plainly. That
is the right licence and we are not changing it.

It has one consequence worth stating: **we cannot count our own adoption.**
Someone could be teaching from this framework in Nairobi today and we would never
know. So any adoption number CRLN publishes is a floor, not a count, and this
file is the only evidence behind it.

That matters beyond vanity. "How many organisations use it" is the first question
a ministry, a funder or a standards body asks, and an answer of "we don't know"
is a worse answer than a small number.

## How to be listed

**The quickest way is the form.** It takes about a minute and needs no GitHub
knowledge beyond an account:

**[Declare that you use CRLN-TRG-001](https://github.com/jwebber-cmyk/crln-trg-001/issues/new?template=adopter-declaration.yml)**

Three other routes work equally well, and none is preferred:

- Email `standard@crln-learn.com` with the fields below. No public trail, which
  some organisations need and others do not care about.
- Open a pull request adding a row yourself.
- Say so on a call, in a reply, or in passing. We will ask your permission before
  anything appears here.

```
| Organisation | Country | Version | How it is used | Link |
```

**Nothing is published without explicit permission.** Entries default to
unpublished and stay that way until you say otherwise.

**What being listed means:** you use the framework. It is not an endorsement of
CRLN, it does not imply you use CRLN's platform, and it creates no obligation.
Ask to be removed at any time and it happens the same day, no questions.

**What we will never do:** add you without asking, imply a commercial
relationship that does not exist, or use this list as a sales prospect list.
